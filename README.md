# Trading Card Wizard

A browser-based trading card generator inspired by the reference image in this repo: `example-card.jpeg`.

## Project Intent

Build a personal card creator so I can generate custom cards for my friends with consistent quality and style.

## End Goal

Create a web tool with:
- Editable text fields (name, stats, flavor text, etc.)
- Sliders and controls for ratings/attributes
- Image upload/replacement for portraits and card art
- Layout controls for symbols, colors, and card details
- Save/load support for repeatable card creation
- High-resolution export (PNG/JPEG) for easy sharing and distribution

## Target Outcome

Given a friend profile, I can quickly fill in fields, tweak visuals, and export a polished high-resolution card in the same overall design language as `example-card.jpeg`.
